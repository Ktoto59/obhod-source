# Участие в разработке

Отправляя изменение, автор соглашается распространять свой вклад по Apache
License 2.0 и подтверждает, что имеет право это сделать.

Перед pull request:

1. Не копируйте чужой код без совместимой лицензии и указания происхождения.
2. Для новой зависимости зафиксируйте лицензию и выполните `npm run licenses:update`.
3. Для нового встроенного бинарника заполните `legal/runtime-components.json`,
   приложите лицензию, точные исходники, инструкцию сборки и SHA-256.
4. Выполните `npm ci` и `npm test` из корня репозитория.
5. При изменении `shared/` или `openwrt/lib/` пересоберите модуль LuCI командой
   `npm run openwrt:core`, затем выполните `npm run test:openwrt:ui`.
6. Добавляйте примеры с `example.com`, `192.0.2.0/24`, `198.51.100.0/24`
   и `203.0.113.0/24`. Не коммитьте рабочие профили, ключи, подписки и журналы.

Windows-код находится в `windows/`, роутерный — в `openwrt/`, общие модели и
парсеры — в `shared/`. Инструкции платформ находятся в соответствующих README.

Разработчикам рекомендуется добавлять `Signed-off-by` (`git commit -s`), тем
самым подтверждая право передать вклад проекту на указанных условиях.
