# Сообщения об уязвимостях

Для непубличного сообщения используйте вкладку **Security → Advisories →
Report a vulnerability** в репозитории. Опишите затронутую версию, условия
воспроизведения и ожидаемый результат.

Не прикладывайте настоящие ключи туннелей, пароли, URL подписок, профили,
резервные копии и полные журналы. Заменяйте адреса и данные подключений
учебными значениями. В обычных Issues можно обсуждать ошибки с обезличенным
примером, не раскрывающим уязвимость.
