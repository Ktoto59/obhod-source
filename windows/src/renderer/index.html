От подключения до работающего сайта

  1. Получите настройки подключения

    В личном кабинете VPN-провайдера или у администратора сервера запросите файл .conf либо ссылку подключения. Обход создаёт собственное подключение: уже запущенный VPN-клиент не заменяет эти настройки.

  2. Импортируйте и проверьте

    Откройте «Подключения», импортируйте файл или ссылку и выполните проверку соединения.

  3. Выберите сайты

    Пресеты — готовые обновляемые наборы доменов. Для своего сайта нажмите «Добавить сайт»: можно вставить полный адрес страницы. Правило охватит домен и его поддомены. После редактирования нажмите «Сохранить» в маршрутизации. Если сервис работает, правила применятся с переподключением.

  4. Включите Обход

    Нажмите «Пуск» на главной. Для резервирования добавьте минимум два подключения и включите автовыбор в его настройках.

Что проверить, если сайт открылся не полностью

Проверьте соединение и журнал. Рекомендуемый режим TUN охватывает приложения и DNS. В настройках DNS проверьте доступность выбранного резолвера — он переводит имена сайтов в IP-адреса. Страница может загружать изображения и API с других доменов: их тоже нужно добавить в правила.

После изменения DNS закройте браузер, выполните в терминале Windows ipconfig /flushdns и откройте сайт снова.
