# Обход 0.17.0

## Более простой интерфейс

- Главная снова показывает только состояние подключения: без прокрутки и лишних настроек.
- Подключения, сайты и приложения вынесены в боковое меню.
- Настройки разделены на основные, автоматический выбор, сеть, перенос настроек и обновления.
- Технические параметры DNS и проверок скрыты в дополнительных блоках.
- Подсказки, мастер настройки и журнал собраны в разделе «Помощь».
- При добавлении сайта можно вставить полный URL: перед сохранением виден итоговый домен.

## Импорт и экспорт конфигурации

- Полная копия подключений и настроек сохраняется в файл `.obhod`, защищённый паролем.
- Можно экспортировать только свои списки сайтов и готовые наборы без данных подключений.
- Перед импортом показывается состав файла; доступны добавление и замена настроек.
- Перед применением сохраняется предыдущий защищённый профиль. При ошибке импорт откатывается.
- Правила программ после переноса выключены и помечены для проверки пути.
- Параметры автозапуска Windows остаются такими, как на текущем компьютере.

## Ядро и восстановление

- Обновлено AWG-совместимое ядро до `1.14.0-rc.1-awgm.15`, с точной ревизией, SHA-256 и инструкцией сборки.
- Исправлены повторные попытки восстановления при ошибке запуска без события завершения процесса.
- Ручная остановка отменяет восстановление и последующие попытки.
- Проверены отказ основного и обоих прокси, потеря DNS и возврат ответов.

Проверки: 70 автоматических тестов и UI-сценарий экспорта/импорта.

Встроенное ядро основано на предварительной RC-версии sing-box. Аппаратные
сценарии сна, гибернации и смены Wi-Fi на Windows пока не прошли ручную матрицу.
Проверка блокировки трафика при отказе серверов относится к работающему ядру;
системный kill switch при завершении самого ядра не реализован.
