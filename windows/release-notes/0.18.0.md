# Обход 0.18.0

## Импорт V2Ray-подписок

- В «Подключения → Вставить ссылку» добавлен режим «Подписка V2Ray».
- Можно загрузить подписку по URL, вставить список ссылок или его Base64-представление.
- Серверы добавляются отдельными подключениями; повторяющиеся настройки пропускаются.
- Поддерживаются VLESS/Reality, Trojan, Shadowsocks, Hysteria2, TUIC, AnyTLS, SOCKS5 и HTTP(S).
- Некорректные и несовместимые записи отменяют импорт всего списка без частичного добавления.
- URL подписки не сохраняется. Для получения новых серверов повторите импорт; автоматического обновления пока нет.
- VMess, конфигурации JSON и YAML пока не поддерживаются.

## Автоматический выбор и интерфейс

- Флажок «Выбрать все» отмечает все подключения группы и позволяет снять выделение повторным нажатием.
- При частичном выборе флажок показывает промежуточное состояние.
- Длинный список названий серверов больше не растягивает карточку маршрута и не выходит за её границы.
- Полный список названий доступен при наведении на сокращённую строку.

Готовые пользовательские туннели и подписки в установщик не включены.
Подключения добавляются пользователем и хранятся в локальном защищённом профиле.

Проверки: 77 автоматических тестов и UI-сценарии импорта, обработки дубликатов,
общего выбора и размещения 50 подключений с длинными названиями.
