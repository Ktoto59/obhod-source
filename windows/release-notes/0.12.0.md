# Обход 0.12.0

## Новые протоколы

- Добавлены профили Hysteria2, TUIC и AnyTLS на встроенном ядре sing-box.
- Поддержан импорт ссылок `hysteria2://`, `hy2://`, `tuic://` и `anytls://`.
- В редакторе показываются только параметры выбранного протокола: Salamander и локальные лимиты скорости для Hysteria2, реквизиты и транспортные параметры TUIC, управление idle-сессиями AnyTLS.
- Все новые протоколы участвуют в проверке подключения, измерении задержки, отображении активного сервера и автоматическом переключении URLTest.

## Безопасность и совместимость

- Схема защищённого профиля обновлена до версии 3 с автоматической миграцией существующих профилей версии 2.
- Пароли, UUID, параметры обфускации и исходные ссылки скрываются из диагностических отчётов и предпросмотра конфигурации.
- Для новых типов добавлена строгая проверка обязательных полей и совместимых параметров.
- Конфигурации всех поддерживаемых протоколов проверяются встроенной командой `sing-box check`.

## Интерфейс и диагностика

- Исправлено отображение протокольных полей: Trojan показывает один пароль, а дополнительные параметры появляются только у соответствующего протокола.
- Уведомления перенесены в правый верхний угол и больше не перекрываются закреплённой панелью сохранения.
- Журнал сервиса вынесен с главной страницы в отдельный пункт левого меню.
- Страница журнала использует доступную высоту окна; прокручивается содержимое журнала, а не всё приложение.

## Подготовка релизов

- Репозиторий настроен на SSH-подпись коммитов, а сценарий публикации проверяет подпись релизного коммита перед созданием GitHub Release.

Настройки, подключения и защищённые ключи сохраняются при обновлении.
