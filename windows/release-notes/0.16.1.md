# Обход 0.16.1

## Открытая лицензия проекта

- Собственный код «Обхода» опубликован по Apache License 2.0.
- В приложение включены `LICENSE`, `NOTICE`, полные тексты лицензий сторонних
  компонентов и их авторские уведомления.
- На экране «О приложении» теперь явно указаны лицензии приложения и сетевого
  ядра.

## Проверяемое сетевое ядро

- Для AWG-совместимого sing-box зафиксированы точная версия, commit и SHA-256.
- Добавлена инструкция воспроизводимой сборки ядра из опубликованных исходников.
- Архив соответствующих GPL-исходников прикладывается к релизу рядом с
  установщиком.
- AmneziaWG-Go привязан к точной ревизии, используемой в сборке ядра.

## Проверки сборки

- Перед тестами проверяются лицензии всех production npm-зависимостей.
- Публикация блокируется при несовпадении версии, commit или SHA-256 встроенного
  ядра, отсутствии лицензии либо неактуальном перечне сторонних компонентов.
- Отдельный пакет лицензий и уведомлений публикуется вместе с установщиком.
- Документированы правила происхождения кода и зависимостей.
