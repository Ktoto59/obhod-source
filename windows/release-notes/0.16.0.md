# Обход 0.16.0

## SOCKS5 и HTTP-прокси

- Добавлены ручные профили и импорт ссылок `socks5://`, `socks://`,
  `http://` и `https://`.
- Поддерживаются подключения с именем пользователя и паролем или без
  авторизации.
- Для SOCKS5 используется нативный SOCKS outbound sing-box, для HTTP и HTTPS —
  нативный HTTP CONNECT outbound.
- Прокси можно использовать в TUN, системном и локальном прокси-режимах, а
  также включать в группы автоматического выбора.

## Проверка и диагностика

- Кнопка проверки временно запускает настроенный маршрут и выполняет реальный
  HTTPS-запрос через прокси. Доступность одного TCP-порта не считается успешной
  проверкой.
- Ошибки DNS, авторизации, отказа сервера, тайм-аута и TLS показываются
  понятным языком.
- Интеграционный тест поднимает локальные HTTP- и SOCKS5-прокси с
  авторизацией, запускает настоящее ядро и проводит запрос через каждый
  маршрут.

## Защита данных

- Имена пользователей и пароли хранятся вместе с профилем в защищённом через
  Windows DPAPI блоке.
- Учётные данные скрываются в диагностике, ссылках, сообщениях об ошибках и
  предварительном просмотре конфигурации.
- Схема профиля обновлена до версии 6; существующие подключения автоматически
  переносятся без удаления настроек.
