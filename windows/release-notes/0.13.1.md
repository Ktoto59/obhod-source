# Обход 0.13.1

## Каталог приложений

- Основным источником выбора стали установленные приложения Windows, а не только уже запущенные процессы.
- Поддержаны обычные Win32-программы и пакетные приложения Microsoft Store: запись приложения сопоставляется с исполняемым файлом из Appx-манифеста. Это позволяет выбирать, например, XBOX до запуска его основного процесса.
- Поиск по запущенным процессам сохранён на отдельной вкладке как резервный вариант.
- Для portable-программ и нестандартных установок по-прежнему доступен ручной выбор одного или нескольких `.exe`.

## Интерфейс

- Прокрутка страницы блокируется, пока открыто модальное окно.
- Внутренний список модального окна больше не передаёт прокрутку фоновой странице при достижении начала или конца.

Настройки, подключения и защищённые ключи сохраняются при обновлении.
