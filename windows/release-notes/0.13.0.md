# Обход 0.13.0

## Маршрутизация приложений

- В настройках маршрутизации появился список запущенных пользовательских приложений с поиском, обновлением и множественным выбором.
- Для незапущенных и portable-программ сохранён ручной выбор одного или нескольких файлов `.exe`.
- Системные процессы и сам «Обход» исключаются из списка, а уже добавленные приложения отмечаются отдельно.
- Для каждого приложения можно выбрать маршрут «через туннель» или «напрямую», временно выключить правило либо удалить его.
- Правило «через туннель» использует активное подключение или текущую группу автоматического переключения.
- Маршрутизация приложений охватывает TCP, UDP и DNS и применяется только в режиме TUN.
- Правила процессов имеют приоритет над доменными пресетами, при этом локальная сеть остаётся доступна напрямую.

## Совместимость и безопасность

- Схема профиля обновлена до версии 4 с автоматическим переносом существующих настроек.
- Проверяется абсолютный путь Windows и расширение `.exe`; дублирующиеся пути автоматически исключаются.
- В диагностическом отчёте сохраняется только имя исполняемого файла без пользовательской части пути.
- Итоговая конфигурация правил процессов проверяется встроенной командой `sing-box check`.

Настройки, подключения и защищённые ключи сохраняются при обновлении.
