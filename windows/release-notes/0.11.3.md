# Обход 0.11.3

## Публикация и доверие

- Релизный процесс создаёт отдельный SSH-подписанный коммит-маркер в публичном
  репозитории перед созданием тега и GitHub Release.
- Скрипт проверяет статус подписи через GitHub API и прекращает публикацию,
  если коммит не получил отметку `Verified`.
- Исправлена совместимость скрипта публикации с Windows PowerShell 5.

Функциональность приложения и пользовательские настройки при обновлении не
изменяются.
