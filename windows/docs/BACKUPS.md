# Перенос конфигурации Обхода

Откройте **Настройки → Перенос настроек**.

## Сохранение

Нажмите **Экспортировать**. Вариант «Все подключения и настройки» сохраняет
подключения, группы, списки, правила программ и сетевые параметры в файл `.obhod`.
Придумайте пароль минимум из 10 символов и повторите его. Для восстановления
понадобится этот пароль; без него прочитать полную копию нельзя.

Вариант «Только свои списки сайтов и готовые наборы» не требует пароля.
В нём нет подключений, внешних URL или путей к программам. Сам список сайтов
в таком файле доступен для чтения.

Экспорт включает сохранённые настройки. Несохранённые изменения сначала
нужно сохранить в соответствующем разделе приложения.

## Восстановление

Нажмите **Импортировать**, выберите файл, введите пароль полной копии.
Приложение покажет количество подключений и правил до любых изменений.

- **Добавить**: подключения и списки добавляются отдельно; текущий маршрут и
  сетевые параметры сохраняются. При пустом списке подключений используется
  импортированный маршрут. Совпадающие подключения не перезаписываются.
- **Заменить**: полная копия заменяет подключения и настройки. При импорте
  только правил заменяются только свои списки сайтов и готовые наборы.

Автозапуск Windows и включение при запуске остаются такими, как на текущем
компьютере. Правила программ из полной копии отключены и помечены для проверки:
сверьте путь к `.exe` в разделе «Сайты и приложения» перед включением.

Перед применением проверяется конфигурация ядра (без проверки доступности каждого
удалённого сервера). Для внешних списков может понадобиться интернет.
Работающий сервис перезапускается. При ошибке возвращаются предыдущие настройки;
если прежний маршрут тоже не запускается, приложение сообщает об этом.
После переноса проверьте нужное подключение кнопкой «Проверить».

## Формат и откат

Полная копия: AES-256-GCM, случайные соль 16 байт и nonce 12 байт, ключ через
scrypt с N=32768, r=8, p=1. Формат имеет собственную версию, ограничение размера
16 МБ и не поддерживает исполнение содержимого. Неверный пароль и изменение
зашифрованных данных не приводят к частичному импорту.

Перед заменой исходный защищённый файл профиля сохраняется рядом с ним как
`profile.json.before-import`. Это локальная копия Windows DPAPI для восстановления
на том же компьютере; её нельзя использовать вместо переносимого `.obhod`.
При сбое она применяется автоматически. Для ручного восстановления закройте
Обход полностью, сохраните текущий `profile.json` отдельно и скопируйте
`profile.json.before-import` на его место в каталоге данных приложения.
