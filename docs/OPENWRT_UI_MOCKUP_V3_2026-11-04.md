# Перенос согласованного макета v3 в LuCI

Источник оформления — `index.html` из предоставленного пользователем
`obhod-ui-mockup-v3.zip`. Изучены HTML, CSS, обработчики вкладок, тем, серверов,
пагинации и массового ввода. Макет не включён в приложение и не нужен для сборки.
Из него перенесены визуальные решения, цвета и SVG-знак; демонстрационные домены,
серверы, версии и результаты проверок не перенесены.

## Что изменено

- `openwrt/luci-app-obhod/htdocs/luci-static/resources/view/obhod/overview.js`:
  компактная шапка, заголовок и breadcrumb выбранного раздела, горизонтальные
  вкладки, двухколоночный обзор, реальные статусы, счётчики и плавающая панель
  несохранённых изменений. Переключатель темы меняет только оформление текущей
  страницы и не делает настройки изменёнными.
- Подключения: отдельное действие раскрытия прежнего импорта, фильтры «Все» /
  «Выбранные», общий поиск, компактные строки и текущие счётчики. Обработчики
  импорта, выбора группы и удаления используют прежние данные приложения.
- Правила: две колонки доменов на широком экране и одна на мобильном, 25 записей
  на страницу, быстрый переход к номеру страницы, диапазон и счётчики, локальный
  поиск и его очистка. Естественная сортировка `Intl.Collator` работает над копией
  полного списка. Массовый черновик и данные для сохранения разделены; редактор
  IP/CIDR расположен в соседнем сворачиваемом блоке. Поиск и выбор страницы не
  делают профиль изменённым. Сохранены валидация, защита от дублей и undo удаления.
- Протоколы: две панели управления ядром и сведений об установке. Версии, наличие
  ядра и размеры берутся из прежних RPC. Опасные действия и блокировки сохранены.
- Сеть: две основные панели и сворачиваемые дополнительные параметры. Прежние
  поля DNS/FakeIP, групп DNS, интерфейсов, IPv6 и QUIC используют прежние значения,
  обработчики и сбор настроек.
- Диагностика: компактные реальные результаты и подробности; сообщения неуспешных
  проверок видны сразу, подробности успешных можно раскрыть. Журнал читается при
  раскрытии, его обновление, очистка и настройка подробности сохранены.
- `openwrt/luci-app-obhod/htdocs/luci-static/resources/obhod/overview.css`:
  цвета, типографика, отступы, карточки, вкладки, переключатели и адаптация из
  макета. Стили ограничены `.obhod-app`. Учтены особенности Bootstrap LuCI:
  `box-sizing` полей и цвет шапки в светлой теме.
- `scripts/check-openwrt-ui.js`: проверки новых контролов, реальных состояний,
  отсутствия наложения полей, контраста шапки, сортировки, прямого перехода на
  страницу и плавающего сохранения; снимки обеих тем.
- Этот файл — отчёт о реализации и проверках.

## Проверки

Пройдены `npm test` (103/103, без пропусков), синтаксическая проверка JavaScript
и `git diff --check`. UI-проверки выполнены с настоящими загрузчиками и DOM из
OpenWrt 24.10.4 и 25.12.6, со стилями Bootstrap 25.12.6:

```sh
npm run test:openwrt:ui -- --luci-loader .tmp/openwrt-tools/luci-24.10.4.js --luci-theme .tmp/openwrt-tools/luci-bootstrap-25.12.6.css
npm run test:openwrt:ui -- --luci-loader .tmp/openwrt-tools/luci-25.12.6.js --luci-theme .tmp/openwrt-tools/luci-bootstrap-25.12.6.css
```

Проверены все шесть вкладок, клавиатурная навигация, обе темы, ширины 320/390 px,
длинные имена, открытые и закрытые редакторы, отсутствие горизонтального
переполнения страницы. Покрыты размеры списка 0, 1, 25, 26, 100, 1000, 5000 и
10000, поиск, удаление найденной записи, последняя страница, undo, URL, дубли,
массовый ввод, сохранение остальных черновиков, общая отмена и повторное открытие
сохранённого полного профиля. Сохранение в этом тесте использует настоящий UI
и прежний upload/apply-код с подменённым RPC.

На 10000 доменов создаются 25 строк и 400 вариантов номера страницы, без
DOM-элементов для невидимых доменов. На компьютере разработчика первая обработка
занимала примерно 25 мс, повторный render и несколько поисковых операций — около
5 мс. Это время JavaScript в Electron, а не замер на мобильном устройстве.
Новых фоновых запросов, таймеров, библиотек или фреймворков не добавлено.

## Проверка и установка на роутере

На Xiaomi Mi Router AX3000T с OpenWrt 25.12.5 установлены только
`/www/luci-static/resources/view/obhod/overview.js` и
`/www/luci-static/resources/obhod/overview.css`. Их SHA-256 сопоставлены с локальными
исходниками. Копия интерфейса до переноса макета находится в
`/root/obhod-ui-v3-backup-20261104-133606`, копия перед окончательной коррекцией
стилей — в `/root/obhod-ui-v3-backup-20261104-133954`.

В настоящей смонтированной LuCI через браузер проверены обзор, правила, поиск по
доменам с разным регистром, удаление и undo, массовый черновик между вкладками,
общая отмена, выбранные серверы, сведения о ядре, сеть и существующие результаты
диагностики. Светлая и тёмная темы просмотрены, дефект цвета светлой шапки исправлен
и повторно проверен. Все тестовые изменения в памяти страницы отменены.

Контрольные суммы backend, `/etc/obhod/settings.json`, `/etc/config/obhod` и PID
sing-box совпали до и после установки и браузерной проверки. Backend, RPC-схема,
генератор, маршрутизация, DNS/FakeIP и lifecycle службы не изменялись.
Служба не перезапускалась, тестовый профиль на роутер не записывался.

## Границы проверки

- Системные результаты из макета заменены данными приложения. До чтения
  диагностики показывается отсутствие результатов, а не успешные DNS/HTTPS-проверки.
  Прочитанные результаты явно относятся к последней диагностике.
- Существующие ограничения сохранения, включая предел профиля 192 КиБ, сохранены.
  Возможность просматривать 10000 доменов не снимает этот предел.
- Физический роутер с OpenWrt 24.10 и аппаратный мобильный браузер не использовались.
  Их совместимость проверена нативным LuCI-загрузчиком/DOM и размерами viewport.
- Сохранение с перезапуском службы на рабочем роутере не проверялось, чтобы не
  менять пользовательскую конфигурацию; этот путь покрыт тестом с подменённым RPC.
- Стандартное меню LuCI остаётся за пределами оформления Обхода. Начальная тема
  определяется прежним способом по теме LuCI; ручное переключение действует до
  перезагрузки страницы.
- Пакетная версия не повышалась, установлен UI-патч. Релиз и merge в `main`
  не выполнялись. При обновлении пакета эти файлы могут быть заменены его сборкой.
