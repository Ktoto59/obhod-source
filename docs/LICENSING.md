# Лицензирование и происхождение кода

Код приложения «Обход» распространяется по Apache License 2.0. Файлы изменений
сетевого ядра в `core/overlay` имеют лицензию GPL-3.0-or-later. Сетевое ядро
sing-box/amnezia-box распространяется по GPL-3.0-or-later и запускается как
отдельный процесс. Полные тексты и уведомления находятся в `LICENSE` и
`LICENSES/`.

## Граница GPL-компонента

- Код из GPL-проектов нельзя копировать, импортировать или линковать с кодом
  `windows/`, `openwrt/` и `shared/`
  без отдельного пересмотра лицензии всего производного произведения.
- Допустимая текущая интеграция — отдельный исполняемый файл с обменом через
  обычную конфигурацию, stdout/stderr и управление жизненным циклом процесса.
- Для каждого распространяемого бинарника обязательны точная ревизия,
  неизменяемая ссылка на исходники, инструкция сборки, SHA-256 и полный текст
  лицензии. Эти данные фиксируются в `legal/runtime-components.json`.
- При публикации релиза архив соответствующих исходников прикладывается рядом с
  установщиком. Скрипт публикации делает это автоматически.

## Новые зависимости

- Не копируйте установочные скрипты или фрагменты чужих клиентов без проверки
  лицензии и сохранения авторских уведомлений.
- Реализуйте интеграции по публичной документации и протоколам в собственном коде;
  сторонние программы устанавливайте как самостоятельные процессы/контейнеры.
- Фиксируйте upstream, лицензию, точный commit/tag, URL архива и хеш. Не
  используйте `latest`, непроверенные `curl | sh` и изменяемые ссылки.
- Добавление copyleft-зависимости в npm или нового встроенного бинарника требует
  отдельного решения до merge.
- Перед релизом выполняйте `npm test`; проверка compliance входит в эту команду.

Это инженерная схема снижения лицензионных рисков, а не юридическое заключение.
Для коммерческого распространения и спорных способов интеграции стоит получить
проверку профильного юриста.
