# Иллюстрации документации

[← Документация проекта](../../README.md)

PNG сняты с настоящих интерфейсов Windows 0.18.0 и OpenWrt 0.1.16.
Вместо пользовательского профиля используются три демонстрационных сервера
из зарезервированных диапазонов 192.0.2.0/24, 198.51.100.0/24 и 203.0.113.0/24,
домены example.com/example.org/example.net и вымышленные показатели состояния.
Они иллюстрируют настройку, а не результаты измерений или действующие подключения.

## Как обновить скриншоты

Из корня репозитория, после `npm ci`:

```sh
npx electron scripts/capture-doc-screenshots.js
```

Для OpenWrt нужны файлы штатного LuCI в `.tmp/openwrt-tools/`:
`luci-25.12.6.js` и `luci-bootstrap-25.12.6.css`. Их извлекает
[`scripts/test-openwrt-system.py`](../../scripts/test-openwrt-system.py) из проверенного
rootfs в изолированной Linux-среде; см. [инструкцию разработки](../../openwrt/docs/DEVELOPMENT.md).
Код LuCI не включается в распространяемые пакеты проекта.

Сценарий открывает исходные страницы и формы, подставляет фиктивный API,
блокирует HTTP/HTTPS-запросы и снимает окна через Electron. Пользовательский
профиль, служба Windows, сетевое ядро и настоящий роутер не запускаются и не читаются.
Временные данные Electron находятся в `.tmp/docs-preview-*`.
При изменении интерфейса переснимите изображения и проверьте их перед коммитом.

Mermaid-схемы хранятся непосредственно в README и отображаются на GitHub.
Они показывают общие маршруты и роли компонентов, не все правила и пакеты протоколов.
