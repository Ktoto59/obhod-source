# Обход для OpenWrt 0.1.3

Исправлена ошибка загрузки страницы LuCI: `"obhod.core" factory yields invalid constructor`.
Модуль парсеров и генератора теперь экспортирует класс `baseclass`, который ожидает загрузчик LuCI.

Добавлена регрессионная проверка через штатный загрузчик из OpenWrt 25.12.6:
тест воспроизводит ошибку старого экспорта, проверяет загрузку исправленного модуля,
импорт подключений, выбор всех серверов, сохранение конфигурации и выбор протоколов.

Обновите пакеты прежней командой установки, затем обновите страницу LuCI через Ctrl+F5.
Сохранённые подключения и настройки сохраняются. Готовых туннелей в пакете нет.

```sh
sh <(wget -O - https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh)
```
