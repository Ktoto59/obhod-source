# Обход для OpenWrt 0.1.18

Исправлены собственные соединения роутера к выбранным доменам. Если dnsmasq
возвращает FakeIP для GitHub или другого выбранного сайта, системные wget,
обновлятор и другие инструменты роутера теперь используют тот же отбор
nftables, что и LAN. Обычный исходящий трафик остаётся в Linux без NFQUEUE.

Сохраняются все изменения 0.1.17: отбор до TUN, сохранение без лишнего
перезапуска, восстановление по сетевым событиям и явные IP-маршруты до sniffing.
Совместимое ядро остаётся `1.13.21-obhod.4`.

Проверены IPv4/IPv6, TCP/UDP, собственные DNS/FakeIP-запросы роутера и отсутствие
прямого трафика в NFQUEUE. Исправление применяется и к сохранённым профилям.

Если на старой версии обновлятор не получает сведения о версии из-за FakeIP,
остановите Обход штатной кнопкой, выполните обновление и затем включите снова.
Профиль сохраняется. Для командной установки используйте опубликованный установщик.
