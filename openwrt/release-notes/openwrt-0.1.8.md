# Обход для OpenWrt 0.1.8

Исправлен воспроизведённый случай прямого выхода выбранного домена: стандартные
300 мс распознавания HTTP/TLS могли истечь до прихода ClientHello. Ожидание
увеличено до 1 секунды. Исправление применяется и к уже сохранённым профилям,
без перезаписи подключений.

Добавлен тест с настоящим sing-box: при задержке 700 мс старая конфигурация
направляет запрос напрямую, исправленная — через прокси; посторонний трафик
остаётся прямым. На AX3000T тот же сценарий до исправления уходил напрямую,
после исправления все контрольные HTTPS-запросы прошли через туннель.

Обновлён интерфейс LuCI:

- Компактный обзор с активным сервером, более плотный список подключений.
- Свои домены перед готовыми списками; сворачиваемые группы со счётчиками.
- Неактивные поля DNS скрыты, панель сохранения закрепляется при изменениях.
- Новая версия, установка и ошибка видны в заголовке обновлений.
- Свёрнутый журнал не загружается при опросе состояния; чтение по раскрытию
  или кнопке обновления. Лимит 32 КБ в tmpfs и скрытие секретов сохранены.

Доменные правила требуют видимого имени из DNS роутера или протокола соединения.
Внешний DoH вместе с ECH по-прежнему может скрыть имя: это исправление не является
системным kill switch и не гарантирует распознавание таких соединений.

После обновления нажмите **Ctrl+F5**.
