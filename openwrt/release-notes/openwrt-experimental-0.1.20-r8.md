# Обход для OpenWrt 0.1.20-r8

Экспериментальный выпуск с sing-box `1.15.0-alpha.13-obhod.1` для OpenWrt 24.10 и 25.12. Пакеты приложения и LuCI доступны для ручной установки. Ядра Lite и Full собраны для ARM64 Cortex-A53 и MIPS 24Kc.

- Диагностика, сохранение и запуск используют одну адаптацию профиля под выбранное ядро. Поддерживаются экспериментальная версия и стабильное ядро `1.13.21-obhod.5`.
- При холодном старте Обход восстанавливает последние рабочие списки из отдельного постоянного кэша. Если кэша нет и настроена загрузка через туннель, ядро пробует участников группы через фактический URL списка.
- В LuCI доступны редактируемый Bootstrap DoH, проверка настроенных DNS и время последнего успешного замера HTTPS с настраиваемым порогом устаревания.
- Исправлены мобильная карточка активного маршрута и обработка границ UDP-пакетов в перехвате DNS.

## Установка для тестирования

Загрузите два пакета приложения для своего менеджера. Для OpenWrt 25.12 это `obhod-0.1.20-r8.apk` и `luci-app-obhod-0.1.20-r8.apk`. Для 24.10 используются соответствующие IPK ревизии 8. Сверьте контрольные суммы по `SHA256SUMS`. Зависимости приложения включают `curl` и `ucode-mod-socket`.

Пакеты `obhod-experimental-core-*` устанавливаются рядом со штатным ядром в `/usr/lib/obhod-experimental/<профиль>/sing-box`. Для проверки запуска с ядром 1.15 используйте отдельный стенд и процедуру из `core/README.md` в архиве исходников. Стабильный канал обновлений продолжает использовать ядро `1.13.21-obhod.5`.
