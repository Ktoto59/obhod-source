# Сетевое ядро Обхода 1.13.21-obhod.5

Стабильная сборка на sing-box 1.13.21 с исправлениями OpenWrt-аудита.
Upstream закреплён: sing-box `628cb31ffa79cffffd34c2f9cde6cae044e4fc12`,
sing-tun `f3b42b8b8e061ef849213a776d9fcf3d5f6ea239`,
sing `87773cc9c5b2a4e4fc05cbd2db304ba23ca13515`.

- FakeIP mappings и курсор выделения сохраняются атомарно. Чтение больше
  не удаляет метаданные; после SIGKILL сохранённые адреса восстанавливаются.
- Redirect routes имеют проверяемую принадлежность Обходу. При старте
  восстанавливаются собственные маршруты после аварии, чужие сохраняются.
- DNS pool ограничивает параллелизм, освобождает ресурсы при отмене,
  ограничивает ожидание отрицательных ответов и сохраняет DNS RCODE.
- Сохранены исправления 31-битных таблиц MIPS, отдельные DNS UDP NAT-сессии,
  обновляемый DNS timeout, отбор адресов до NFQUEUE и классификация ICMP logs.
- В IPK исправлен список сохраняемых конфигурационных файлов для opkg.

Восемь пакетов: ARM64 Cortex-A53/MIPS little-endian 24Kc × lite/full ×
APK для OpenWrt 25.12/IPK для 24.10. Package revision 500 следует за 300/400:
`1.13.21-r500` и `1.13.21-500`. Full включает WireGuard.
Предыдущие `.4` не изменяются и остаются доступны.

Для безопасного отката opkg приложены четыре отдельных пакета `1.13.21-401`:
они содержат неизменённый payload `.4` с исправленными conffiles. Выбор `.4`
в новом приложении на OpenWrt 24.10 использует 401. Прямой downgrade на старый
`-400` не рекомендуется из-за известного дефекта его метаданных.
Установщик сохраняет содержимое, права и владельцев конфигураций, восстанавливает
их после прерывания и проверяет SHA-256 установленного ELF. Системные метаданные
opkg не подменяются. Для APK сохраняется откат на оригинальный `r400`.

зависимости, notices и автономный рецепт сборки Go 1.26.10. Компилятор
устанавливается отдельно. SHA-256 и размеры находятся в `SHA256SUMS`
и `packages.json`, хеши overlay и upstream SHA — в `build-manifest.json`.

Ограничения: клиентский DoH/DoT, обычный IPv6 при отключённой обработке,
отсутствие глобального kill switch. Проверки в изолированной среде
не заменяют проверку dnsmasq/procd и драйверов конкретного роутера.
