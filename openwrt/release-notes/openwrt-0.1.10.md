# Обход для OpenWrt 0.1.10

Добавлен режим DNS FakeIP по принципу Podkop: выбранные домены получают служебные
адреса, по которым sing-box восстанавливает имя и применяет общие правила до
распознавания HTTP/TLS. Это убирает зависимость от ClientHello для запросов,
которые используют DNS роутера. Обычные сайты получают реальные адреса и идут напрямую.
TCP и UDP проверены на настоящем sing-box. Все туннели используют одну политику;
автоматическая группа служит для выбора рабочего соединения и резерва.

- На вкладке «Сеть» выбираются FakeIP/прежний режим, общий DNS, протокол,
  bootstrap и TTL. У старых профилей режим сохраняется до явного переключения.
- Кэш FakeIP находится в ОЗУ, переживает перезапуск службы и исчезает после
  перезагрузки роутера. Кэш dnsmasq отключается с восстановлением при остановке.
  Диагностика проверяет выдачу FakeIP через локальный dnsmasq.
- Свои домены: поиск, удаление, страницы по 50 записей и массовое редактирование.
- «Отменить» возвращает последний сохранённый профиль без остановки службы.
  При работающей службе действие сохранения называется «Применить изменения».
- Размеры облегчённого и полного ядра берутся из индексов apk/opkg роутера:
  отдельно загрузка и размер после распаковки, без зависимостей.
- Добавлены URL и расширенные интервалы проверки туннелей, период обновления
  списков, загрузка списков через туннель и отключение клиентского QUIC.

Клиенты должны использовать DNS роутера; собственный DoH/Private DNS и другой VPN
могут обходить его DNS-политику. После включения FakeIP старые DNS-ответы на устройствах
должны обновиться. После обновления LuCI нажмите **Ctrl+F5**.
