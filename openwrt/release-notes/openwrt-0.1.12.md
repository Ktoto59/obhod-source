# Обход для OpenWrt 0.1.12

Установка ядра протоколов запускается через procd и не зависит от жизни RPC-запроса
или страницы LuCI. Если фоновую задачу запустить не удалось, блокировки снимаются
сразу. Для не запустившегося процесса предусмотрено восстановление через 30 секунд;
поздний запуск уже отменённой задачи не начинает установку.

Опрос состояния распознаёт завершившиеся процессы, включая зомби. Если apk/opkg
ещё работает, блокировка сохраняется до его завершения.

Ход установки теперь виден во всех разделах. Можно переключать вкладки,
редактировать и отменять черновик. Применение настроек и запуск службы ждут
окончания установки ядра; подсказка сообщает конкретную причину ожидания.

Проверено в изолированных OpenWrt с apk и opkg: нормальное завершение, ошибка
запуска, отсутствие рабочего процесса, зомби, поздний запуск и работающий
пакетный менеджер.

После обновления нажмите **Ctrl+F5**.
