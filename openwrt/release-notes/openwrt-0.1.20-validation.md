# Проверка OpenWrt 0.1.20 — 7 ноября 2026

Приложение: **0.1.20**. Сетевое ядро: **1.13.21-obhod.5**, без изменений
бинарников и каталога совместимых ядер. Исходники приложения закрепляются
тегом `openwrt-v0.1.20`; точный commit указывается в provenance релиза.

На физическом Xiaomi AX3000T с OpenWrt 25.12.5 и ядром .5 установлены и проверены
эти исправления. Два последовательных restart через настоящий procd завершились
успешно, PID dnsmasq не менялся. В выборке DNS для выбранного разрешённого имени
получены 16 FakeIP-ответов и 10 кратких тайм-аутов; реальных IP не получено.
После перезапусков выбранный блокируемый домен возвращал sinkhole, HTTPS
разрешённого сайта работал через туннель. Действующие файлы сверены с исходниками
по SHA-256. Это проверка одного устройства, а не всех моделей/архитектур.

## Проверки выпуска

Полный `scripts/test-openwrt-system.py`: 20 групп проверок passed, exit 0.
Проверены установка новых пакетов APK/IPK, переход с **повторно скачанной
официальной 0.1.19** её собственным обновлятором при отсутствии socket-модуля,
откат 0.1.20 → 0.1.19 → 0.1.20 с сохранением профиля и UCI/DNS. Пакеты .19
сверены с опубликованным SHA256SUMS. Отдельно проверены ошибка подготовки
компонента, повторный запуск и повторное использование установленного модуля.
Использованы сетевой namespace и одноразовые OpenWrt rootfs; системные службы
хоста не изменялись. PID1/procd в этих пакетных тестах представлены фикстурой.

Проверка скачанных публичных файлов выполняется после публикации и фиксируется
в описании GitHub Release; локальные проверки не выдаются за публичные.

Локальные инструкции, память Codex, рабочие профили, ключи и журналы в исходный
архив и пакеты не включаются. Публичный канал обновления активируется после
проверки опубликованных файлов. Windows Latest остаётся `v0.18.0`.
