# Обход для OpenWrt 0.1.19

Стабильный выпуск приложения с обновлённым LuCI и совместимым ядром
`1.13.21-obhod.5`. Экспериментальный sing-box 1.15 в комплект не входит.

## Новое

- Переработанный интерфейс, оформление штатной темой LuCI, светлый и тёмный
  режимы, адаптация к узким экранам. Новый редактор доменов работает
  постранично с большими списками, сохраняет ввод и показывает ошибки.
- Улучшенная телеметрия: свежесть измерений, пассивное чтение истории
  urltest и диагностика по запросу. Время журнала учитывает часовой пояс роутера.
- Ядро `.5` с исправлениями FakeIP, DNS exchange и восстановления маршрутов.

## Исправлено

- Транзакции DNS apply/restore, восстановление после прерывания, гонки с
  UCI commit и остановкой службы. Чужие настройки DNS сохраняются.
- Блокировки операций, восстановление stale jobs, исключение конкурирующих
  apply, обновлений и переключений ядра; обработка отказов остановки.
- Сохранение FakeIP после SIGKILL и очистка только собственных redirect routes.
- Ограничение ресурсов DNS pool, освобождение отменённых запросов и корректные
  отрицательные ответы. Сохранена изоляция DNS UDP от остальных NAT-сессий.
- Лишние перезапуски и проверки: одинаковый профиль использует безопасный
  no-op apply при неизменных исходниках и работающей службе.

Крупные профили передаются порциями. Журнал читается в пределах 32 КБ,
не записывается постоянно во flash; секреты скрываются в интерфейсе.

## Совместимость и обновление

OpenWrt 24.10/opkg и 25.12/apk; ядро ARM64 Cortex-A53 и MIPS little-endian
24Kc, lite/full. Для WireGuard требуется full. Версии пакетов ядра:
`1.13.21-r500` (APK) и `1.13.21-500` (IPK).

Перед обновлением с 0.1.18 сохраните резервную копию `/etc/obhod`,
`/etc/config/obhod` и `/etc/config/dhcp`. Используйте штатный обновлятор или
установщик из одного релиза. Подключения, правила, подписки, DNS и enabled
сохраняются. Совместимое работающее ядро не заменяется одним фактом выхода .5;
выберите .5 во вкладке «Протоколы» для получения новых исправлений.
Старые пакеты остаются доступны для восстановления.

На OpenWrt 24.10 откат ядра на `.4` выполняется через отдельную совместимую
revision `1.13.21-401` с тем же бинарником `.4`. Это исправляет каталог в
conffiles оригинального `-400` без изменения старых файлов и тегов. Конфигурация,
права и владельцы сохраняются транзакционным помощником, который также проверяет
установленный ELF. Для APK остаётся прежний `r400`.

## Ограничения

Клиентский DoH/DoT может обходить DNS роутера. При отключённой обработке IPv6
выбранным доменам не выдаются AAAA, обычный IPv6 остаётся в Linux.
Глобального kill switch нет. Поведение dnsmasq, procd, offload и сетевых
драйверов необходимо проверять на конкретном оборудовании. Проверки WSL,
chroot и эмуляции не доказывают совместимость со всеми роутерами.
