# Обход для OpenWrt 0.1.15

- Стандартный DNS по TCP/UDP на порту 53 перехватывается до сниффинга,
  правил доменов и прямого выхода. Поздний DNS-over-TCP запрос к служебному
  адресу TUN больше не направляется в direct с ошибкой loopback.
- Обновлён каталог совместимых ядер до 1.13.21-obhod.3 с изоляцией DNS/STUN
  и сохранением отрицательных ответов DNS-провайдера.
- Запасной DNS-пул для штатного ядра использует ту же обработку REFUSED/SERVFAIL.
- Изменения правил применяются к рабочей копии конфигурации при запуске;
  пользовательские подключения, ключи, DNS-серверы и списки сохраняются.

Установочный скрипт выбирает новое совместимое ядро автоматически. После
обновления только приложения через LuCI ядро обновляется отдельно: выключите
службу, установите выбранный набор во вкладке «Протоколы» и снова включите её.
