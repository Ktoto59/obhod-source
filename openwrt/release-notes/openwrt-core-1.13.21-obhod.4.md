# Сетевое ядро Обхода 1.13.21-obhod.4

- При положительном `route_address_set` nftables отсекает невыбранные адреса
  до NFQUEUE. Обычные TCP/UDP-соединения с первого пакета остаются в Linux.
- Используется тот же обновляемый набор адресов, что и в auto_redirect:
  FakeIP, свои подсети и IP-части выбранных списков.
- Сохраняются штатный DNS hijack и все исправления DNS/UDP из .3.

APK для OpenWrt 25.12 и IPK для 24.10: ARM64 Cortex-A53 и MIPS little-endian
24Kc, варианты lite/full. Полный вариант включает WireGuard.

Исходники, зависимости и рецепт автономной сборки прилагаются. Изменения ядра
распространяются по GPL-3.0-or-later. Проверены настоящий Linux nftables/TUN,
IPv4/IPv6, TCP/UDP, обновление JSON/SRS и запуск с кэшем при отказе источника.
На физическом роутере проверен ARM64; MIPS проверен сборкой.
