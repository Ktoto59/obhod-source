# Обход для OpenWrt 0.1.1 — тестовый выпуск

LuCI и служба выборочной маршрутизации для OpenWrt 24.10 (opkg/IPK) и 25.12 (apk/APK v3).

## Установка одной командой

```sh
sh <(wget -O - https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh)
```

Если оболочка не поддерживает `<(...)`:

```sh
wget -O /tmp/obhod-install.sh https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh && sh /tmp/obhod-install.sh
```

- Проверяется общий и доступный объём ОЗУ, свободное место накопителя и `/tmp`.
- Размер недостающих зависимостей рассчитывается по APK solver/opkg dry-run с запасом места.
- Пакетный менеджер определяется автоматически. Зависимости устанавливаются из репозиториев прошивки.
- В меню доступны рекомендуемые списки, минимальный набор, выбор по номерам и установка без готовых списков.
- Выбор появляется в LuCI. Существующий профиль с подключениями и правилами сохраняется.
- Архив закреплён по версии и SHA-256; перед установкой проверяются контрольные суммы файлов.
- `--yes --check-only` выполняет проверку без установки пакетов и изменения настроек.

Поддерживаются импорт V2Ray-подписок и WireGuard, домены/подсети, готовые списки,
группы автоматического выбора и общий флажок выбора серверов. Управление:
**LuCI → Службы → Обход**. Готовые туннели и URL подписок не включены.

Минимальный бюджет установки: 128 МБ ОЗУ, 48 МБ доступной памяти и 16 МБ в `/tmp`.
Для накопителя используется размер пакетов после распаковки плюс запас 8 МБ.
Проверки пройдены в изолированных OpenWrt 24.10/25.12, а также в браузерном стенде
и 82 автоматических тестах. На физических AX3000T и SmartBox TURBO+ ещё не проверено.
AmneziaWG и VMess пока не поддерживаются. Это предварительный выпуск,
он не меняет канал автообновлений Windows.
