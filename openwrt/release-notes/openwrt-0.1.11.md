# Обход для OpenWrt 0.1.11

FakeIP стал единственным способом DNS-маршрутизации. Переключатель старого режима
удалён из LuCI. Выбор общего DNS, протокола, bootstrap и TTL сохранён.

Старые профили автоматически получают FakeIP в рабочей конфигурации при запуске
службы. Сохранённые туннели, ключи, выбор серверов и общие правила не переписываются.
Проверки диагностики и управление кэшем dnsmasq больше не зависят от старого поля режима.

Выбранные домены используют FakeIP и направляются через активный туннель;
остальные сайты получают реальные адреса и идут напрямую. Клиенты должны использовать
DNS роутера. После обновления нажмите **Ctrl+F5**.
