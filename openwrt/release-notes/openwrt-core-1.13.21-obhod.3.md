# Сетевое ядро 1.13.21-obhod.3

- Сохраняются корректные отрицательные DNS-ответы провайдера, включая REFUSED
  и SERVFAIL. Они возвращаются клиенту, если другой сервер не дал успешного
  ответа. Намеренный отказ DNS-фильтра больше не превращается в сообщение
  «all DNS pool members failed». Настоящие ошибки транспорта остаются ошибками.
- В TUN DNS-сессии UDP/53 отделены от остальных UDP-сессий с тем же исходным
  портом. STUN/WebRTC больше не попадает в DNS-парсер из-за повторного
  использования порта. Для остальных UDP-портов сохраняется общая сессия,
  необходимая для обычной работы P2P.
- Для перехваченного DNS применяется 10-секундный тайм-аут с обновлением при
  каждом запросе; общий тайм-аут других UDP-соединений не сокращается.
- Сохраняются исправление 32-битных номеров таблиц MIPS и встроенные DNS-группы.

Основа: sing-box 1.13.21, sing-tun v0.8.15 и sing v0.8.14. Доступны облегчённые
и полные APK/IPK для MIPS/ARM64, контрольные суммы и соответствующие исходники.
