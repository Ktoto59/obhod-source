# Обход для OpenWrt 0.1.4

Интерфейс LuCI разделён на пять вкладок: Обзор, Подключения, Правила, Протоколы и Сеть.

- Обзор со статусом, текущим маршрутом и краткой сводкой.
- Карточки, широкие поля, светлая и тёмная темы, адаптация под телефон.
- Поиск серверов, сворачиваемый импорт и компактная настройка автоматического выбора.
- Списки сгруппированы по регионам, сервисам, категориям и сетям. Несовместимые наборы отключаются сразу.
- Общая нижняя панель сохранения; введённые данные сохраняются при смене вкладок.
- Исправлены чекбоксы: LuCI больше не получает атрибут `checked="false"`, который ошибочно включал невыбранные настройки.

Проверено со штатным загрузчиком и DOM LuCI, темой Bootstrap, светлым и тёмным оформлением, ширинами 320 и 390 пикселей. Проверены APK/IPK и сохранение существующих настроек. Сохранённые профили не перезаписываются.

Обновите пакеты прежней командой, затем нажмите Ctrl+F5 на странице Обхода:

```sh
sh <(wget -O - https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh)
```
