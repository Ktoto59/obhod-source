# Обход для OpenWrt 0.1.13

- В разделе «Сеть» можно настроить группу из 2–4 DNS-серверов. Поддерживаются
  UDP, TCP, DoT и DoH, отдельные порты и пути провайдера.
- Параллельный режим принимает первый ответ NOERROR/NXDOMAIN. Ошибка SERVFAIL
  одного сервера не перебивает успешный ответ остальных. Автоматический режим
  сначала опрашивает известный рабочий сервер и подключает резервные при задержке.
- Bootstrap поддерживает несколько IP-адресов и тот же режим выбора.
  Он работает независимо от sing-box, в том числе при холодной загрузке списков.
- FakeIP сохраняется для клиентских запросов. Реальный DNS выбранных доменов
  остаётся внутри туннеля; отказ прокси-DNS не переключает запросы напрямую.
- Дополнительный socket-модуль устанавливается кнопкой «Подготовить DNS-группы»
  из штатного репозитория OpenWrt. Группы работают как отдельные задачи procd,
  с ограничением числа запросов и памяти, без журналирования доменов.
- Существующие настройки остаются в режиме одного сервера до явного включения
  группы. Ключи, подключения и правила при обновлении сохраняются.

Проверены настоящий sing-box 1.12.22 и ucode OpenWrt: молчащий DNS, SERVFAIL,
UDP/TCP и большие ответы, параллельные DNS-ID, резерв bootstrap и отсутствие
прямого DNS-выхода при отказе туннеля. UI проверен штатными загрузчиками LuCI.
На AX3000T с OpenWrt 25.12.5 и sing-box 1.13.21 проверены установка,
подготовка socket-модуля через LuCI и параллельный опрос двух DoH-серверов:
диагностика 7/7, профиль сохранён. Три DNS-процесса занимают около 3,7 МиБ RSS
в сумме на этом устройстве; ответы и журналы запросов в них не накапливаются.
