# Обход для OpenWrt 0.1.2

- Облегчённая установка с `sing-box-tiny` для VLESS/Reality и других прокси.
- Выбор протоколов в установщике и через LuCI после установки, включая установку только интерфейса без ядра.
- Фоновая установка и переключение tiny/full с проверкой памяти, состояния службы и сохранённых WireGuard-подключений.
- Жёсткие пороги ОЗУ удалены: объём памяти показывается как предупреждение. Для крупных зависимостей начальная проверка требует 15 МБ flash; несжатый размер показывается как оценка, окончательный контроль выполняет apk/opkg.
- Минимальные списки по умолчанию на малых устройствах. Удалена обязательная зависимость от curl; используется штатный uclient-fetch.
- Исправлена проверка онлайн-комплекта: соседние файлы в /tmp не могут подменить загрузку закреплённого архива.
- Метаданные размеров и контрольных сумм opkg читаются из индексов: штатный `opkg info` эти поля не выводит.

Установка: `sh <(wget -O - https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh)`

Пакеты службы и LuCI подходят для всех архитектур; sing-box и модули устанавливаются из репозитория прошивки. Формат APK/IPK выбирается автоматически. Готовых туннелей, ключей и подписок нет. Проверено в изолированных OpenWrt userspace; производительность и маршрутизация на физических AX3000T и SmartBox TURBO+ ещё не измерены.
