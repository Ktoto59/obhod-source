# Совместимое ядро для OpenWrt MIPS / MT7621

Облегчённый sing-box 1.13.21 с исправлением переполнения номера таблицы
маршрутизации на 32-битных устройствах, включая ASUS RT-AX53U.
Бинарник сообщает `1.13.21-obhod.1`, пакет имеет версию `1.13.21-r100`.

При переполнении auto_redirect мог записывать `local 127.0.0.1` в `main` и
завершаться с `append redirect route ... Table: -...: file exists`.
Случайный номер таблицы теперь ограничен 31 битом.

`install-mips-core-fix.sh` предназначен для `ramips/mt7621`, OpenWrt с apk
и установленным sing-box-tiny. Он сохраняет настройки, останавливает Обход,
проверяет SHA-256 APK, заменяет ядро, удаляет только ошибочный loopback-префикс
из `main` и запускает службу. Маршруты и настройки WireGuard не очищаются.
Полное ядро с WireGuard и прошивка роутера не заменяются.

Проверено на SmartBox с MT7621 / OpenWrt 25.12.6: шесть последовательных запусков
и ещё три с тремя активными IPv4-интерфейсами; положительные номера таблиц,
сохранность профиля, DNS и HTTPS через туннель. Установщик также проверен
в изоляции на примере маршрутов ASUS, включая ошибки загрузки/установки.
IPK приложен для ручной установки; аппаратная проверка выполнена с APK.

Архив соответствующих исходников включает используемые Go-модули и рецепты сборки.
Автономная повторная сборка Go 1.26.8 дала побайтно тот же бинарник.

Это отдельное обновление ядра. Обход остаётся своей текущей версии.
