# Обход для OpenWrt 0.1.14

- При установке протоколов автоматически определяется архитектура и версия
  OpenWrt. Для поддерживаемых MIPS/ARM64 выбирается совместимое ядро Обхода;
  для остальных платформ сохраняется установка штатного пакета OpenWrt.
- В MIPS-сборках исправлено переполнение номера таблицы `auto_redirect`,
  приводившее к отрицательным значениям и ошибочным loopback-маршрутам в `main`.
- С совместимым ядром DNS-группы работают внутри sing-box, без дополнительных
  DNS-процессов и socket-модуля. Со штатным ядром сохраняется прежний механизм.
- Совместимый пакет проверяется по размеру и SHA-256. Зависимости загружаются
  из подписанных репозиториев OpenWrt; настройки сохраняются перед заменой ядра.
- Обновление приложения само по себе не заменяет установленное ядро. Для
  перехода используется установка протоколов в LuCI или установочный скрипт.
