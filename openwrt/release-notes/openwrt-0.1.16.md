# Обход для OpenWrt 0.1.16

- Во вкладке «Протоколы» добавлен выбор версии ядра для полного и облегчённого
  набора: рекомендованная 1.13.21-obhod.3 и предыдущая 1.13.21-obhod.2 для отката.
  Список учитывает архитектуру и версию OpenWrt, размеры соответствуют выбранной сборке.
- Добавлено удаление ядра после выключения службы, с подтверждением и сохранением
  подключений, DNS и списков. Удаление отклоняется, если оно затронет другие пакеты.
- Добавлен асинхронный перезапуск службы с сохранённой конфигурацией.
- Результаты диагностики выделены зелёными и красными карточками с текстом и символами.
- Установка, удаление, перезапуск и обновление используют общую блокировку операций.
  Для opkg предусмотрен проверенный пакет отката и при смене совместимых версий ядра.

Обновление самого Обхода сохраняет установленный вариант и версию sing-box.
Смена версии ядра выполняется отдельно во вкладке «Протоколы».
