# Обход для OpenWrt 0.1.5

На вкладке «Обзор» появился раздел обновления самого Обхода:

- Проверка новой версии и установка через LuCI без SSH.
- Фоновая задача под procd, независимая от вкладки браузера и перезагрузки rpcd.
- Проверка SHA-256 архива, формата метаданных и путей перед распаковкой.
- Сохранение подключений и списков, восстановление включённой службы после установки.
- Защита от потери несохранённых изменений и кнопка открытия новой версии страницы.

Запросы Обхода больше не объединяются в RPC-пакеты. Данные версии ядра кэшируются,
а временный сбой опроса состояния не создаёт поток уведомлений «No related RPC reply».
rpcd перечитывает конфигурацию с сохранением сессий вместо полного перезапуска.

Для перехода с 0.1.4 и более ранних версий обновите пакеты привычной командой и нажмите Ctrl+F5:

```sh
sh <(wget -O - https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh)
```

После этого следующие обновления доступны через **Обзор → Обновления Обхода**.
Обновление приложения и установка ядра протоколов выполняются отдельно.

Проверен реальный переход с 0.1.4 на 0.1.5 на SmartBox с OpenWrt 25.12.6 через
HTTP/RPC: все 50 подключений и контрольная сумма профиля сохранились, включённая
служба и DNS восстановились. Авторизованная сессия LuCI сохранилась после reload rpcd.
